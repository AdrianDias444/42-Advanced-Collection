# SCOP


## You will implement a 3D Viewer
    - You are free to pick any language,
    but like the subject says C, C++ and Rust
    are highly recomended

    - Also Zig is a great choice.
    Fck Makefile and header files.
    
[Why doesn't zig have header files](https://ziggit.dev/t/why-doesnt-zig-have-header-files/7587) 

## You can choose any of these 3 Graphics APIs
    - OpenGl, Vulkan or Metal. They are essential for 
    this project because the concept of SCOP is
    GPU Rendering.
    
    - You will use these specific APIs
    for update in runtime the vertices of a obj file.
    
    - Before making the rendering you need to parse the vertices of the object. Can't be that hard
